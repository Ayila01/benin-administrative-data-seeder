# Structuration des données administratives du Bénin

Projet de collecte et de structuration des données administratives du Bénin à partir des données de l'INSAE.

## Description

Ce projet consiste à structurer les données administratives du Bénin sous forme de données exploitables dans une base de données.

Les données comprennent notamment :
- Départements
- Communes
- Arrondissements
- Villages
- Quartiers de ville

## Technologies

- PHP
- MySQL
- Laravel / Seeders

## Objectif

Faciliter l'intégration et l'exploitation des données administratives dans des applications web et des bases de données relationnelles.

## Structure des données

Les différentes entités administratives sont organisées selon leur hiérarchie :

Département → Commune → Arrondissement → Village / Quartier de ville

## Source des données

Données administratives issues de l'INSAE.
